## Короткие команды

Введите сокращение и нажмите `Tab` дважды, чтобы развернуть фрагмент. Доступность сокращений зависит от установленных фрагментов и настроек редактора.

| Сокращение | Что вставляет |
| :--- | :--- |
| `cw` | `Console.WriteLine` |
| `if` | Блок условия `if` |
| `else` | Блок `else`; в списке подсказок его можно найти по началу `el` |
| `for` | Цикл `for`; в подсказках можно начать с `fo` |
| `forr` | Обратный цикл `for` |
| `cr` | `Console.ReadLine()` после установки файла ниже |
| `ip` | Ввод целого числа через `int.Parse` после установки файла ниже |
| `main` | Заголовок `Main` после установки файла ниже |

<details markdown="1">
<summary>Сокращения для следующих тем</summary>

| Сокращение | Что вставляет |
| :--- | :--- |
| `while` | Цикл `while`; в подсказках можно начать с `wh` |
| `foreach` | Цикл `foreach`; в подсказках можно начать с `fore` |

## Добавление готовых фрагментов

1. [Скачайте файл rl.snippet]({{ '/cs/rl.snippet' | relative_url }}), содержащий `cr`, `ip` и `main`.
2. Откройте проводник и перейдите в свою папку **Документы**.
3. Для Visual Studio 2026 найдите папку `Visual Studio 18`, затем `Code Snippets`, `Visual C#`, `My Code Snippets`. Название папки зависит от установленной версии Visual Studio.
4. Скопируйте скачанный файл в эту папку. Пример полного пути:

```text
%USERPROFILE%\Documents\Visual Studio 18\Code Snippets\Visual C#\My Code Snippets
```

После установки введите `ip` и дважды нажмите `Tab`. Должен появиться такой код:

```csharp
Console.Write("Enter a number: ");
int num1 = int.Parse(Console.ReadLine());
```

Сообщение можно заменить на `"Введите число: "`, а имя `num1` — на подходящее вашей задаче.

## Редактирование кода

Запись `Ctrl + K, C` означает: нажмите `Ctrl + K`, отпустите клавиши, затем нажмите `Ctrl + C`. Сочетания могут отличаться в выбранном профиле клавиатуры.

| Сочетание | Действие |
| :--- | :--- |
| `Ctrl + K, C` | Закомментировать выделенные строки |
| `Ctrl + K, U` | Убрать комментарии с выделенных строк |
| `Ctrl + /` | Переключить комментарий, если команда назначена в вашем профиле |
| `Ctrl + K, D` | Отформатировать документ |
| `F12` | Перейти к определению переменной или метода |
| `Ctrl + Z` | Отменить действие |
| `Ctrl + Y` | Повторить отменённое действие |
| `Ctrl + D` | Дублировать строку, если это действие назначено в настройках |
| `Ctrl + Shift + .` | Увеличить текст |
| `Ctrl + Shift + ,` | Уменьшить текст |
| `Ctrl` + колесо мыши | Изменить масштаб текста |
