## Подготовка решения

1. Откройте задание в [CodeClassroom](https://codeclassroom.io). Для присоединения к классу используйте код, который вам выдали.
2. Скопируйте **заголовок метода** из окна решения. Это строка с именем метода, его параметрами и типом результата.
3. Вставьте заголовок внутрь класса `Program`, рядом с `Main`, и добавьте фигурные скобки `{ }`.
4. Если метод не принимает параметров, вызовите его из `Main`, как в примере ниже. Имя должно совпадать с именем в задании.

Метод — это блок кода с именем. Здесь он нужен, чтобы запустить решение задания. Подробнее методы вы изучите позднее.

```csharp
using System;

namespace ConsoleApp111
{
    internal class Program
    {
        public static void DefineIntVariables()
        {
            // Напишите здесь решение по условию задания.
        }

        static void Main(string[] args)
        {
            DefineIntVariables();
        }
    }
}
```

{: .box-warning}
Одного объявления метода недостаточно: чтобы код внутри выполнился, метод нужно вызвать. В примере это строка `DefineIntVariables();` внутри `Main`.

<details markdown="1">
<summary>Другой способ записи пространства имён</summary>

Вместо блока `namespace ConsoleApp111 { ... }` проект может использовать строку `namespace ConsoleApp1;`. Выберите один из этих вариантов записи.

```csharp
using System;

namespace ConsoleApp1;

public class Program
{
    public static void DefineIntVariables()
    {
        // Напишите здесь решение по условию задания.
    }

    public static void Main(string[] args)
    {
        DefineIntVariables();
    }
}
```

</details>

## Проверка и отправка

1. Решите задачу в Visual Studio.
2. Запустите программу. Проверьте обычные случаи и граничные значения, допустимые по условию.
3. Скопируйте **метод целиком**, включая заголовок и фигурные скобки, обратно в окно решения. Соблюдайте формат, указанный в задании.
4. Отправьте решение и изучите результат проверки. Если оно не прошло, сравните ожидаемый и фактический вывод и исправьте программу.

{: .box-note}
Если система сравнивает вывод автоматически, печатайте только то, что требуется в задании. Дополнительная фраза вроде «Введите число» может изменить результат проверки.
